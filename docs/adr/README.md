# Architecture Decision Records

I write these. Claude Code reviews them but does not write them. One file per decision,
numbered: `0001-short-title.md`. Write one when there is a real choice between options and
a downside you are accepting. Never edit an accepted ADR; supersede it with a new one.

## Template
```
# ADR-0000: Title

- Status: Proposed | Accepted | Superseded by ADR-0000
- Date:

## Context
What forces are at play? What problem are we solving, and what constraints apply?

## Options considered
1. Option A: pros, cons
2. Option B: pros, cons

## Decision
What we chose, in one or two sentences.

## Consequences
What gets easier. What gets harder. The downside I knowingly accepted. What would make me
revisit this.
```
