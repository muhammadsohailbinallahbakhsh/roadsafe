# Learning Prompt

Use this in a NEW thread inside the Claude Project "Road Accident Project", before a step
whose technology is new to me. Fill the four brackets. The step's "Learn first" column in
ROADMAP.md tells me the topic and a starting resource.

```
I'm about to start RoadSafe step [STEP ID and NAME]. I'm new to [TOPIC].
The outcome I must reach: [DONE-WHEN from ROADMAP].
Teach me only what I need for that outcome, in about [N] hours.

For each stage give: the idea in 2-3 lines, one hands-on exercise I can do outside the
project repo, and a "you're ready when" check. Name the single best free resource per
stage, and check the current docs before recommending a link. Do not write my project
code. Quiz me at the end with 5 questions, and tell me what to ask Claude Code to
confirm I'm ready.
```

If the thread finds that the topic is bigger than the step assumes, tell the strategy
thread so we can decide whether to split the step.
